## 一、最终架构定版（纯静态仓库 + Antigravity 驱动更新）

- **仓库与托管**：GitHub Public 仓库 `Guess00/oshi-calendar` + **GitHub Pages**（`https://guess00.github.io/oshi-calendar/`），纯 0 元零构建静态托管。
- **更新入口与自动化约定**：
  - 仓库根目录放置 `AGENTS.md`，每次在 `d:\nsy-helper` 项目下打开新对话对 Antigravity 说「更新一下」，即自动触发完整更新流程。
  - 更新推送模式由 `data/config.json` 中的 `pushMode` 控制：当前默认 **`"W1"`**（先汇报变更清单，用户确认后 commit & push）；后续用户说「切到 W2」即可改写为 **`"W2"`**（更新完直接自动 commit & push 并汇报摘要）。
- **第 1 阶段范围（橘杏咲）**：
  - 推特记录 INS 头像栏仅放橘杏咲本人官号 `@anzusaku1012`（原创 + RT，放弃 Replies，严格保持 X 主页顺序，零正文零图文，点击新标签页跳转原链）。
  - 日程更新同时覆盖：番剧排期（AniList / しょぼいカレンダー）、Eventernote（ID `71494`）、YouTube GA文庫チャンネル『パジャナイ』RSS、关联节目官推 `@pazyanai_chan`（仅用于提取日程，不占推特头像栏）、每月 1 号声グラ专栏固定规则，以及 `@anzusaku1012` 近期推文中的嘉宾/活动提取。

## 二、已确认决策总表（结论 + 理由）

| 编号 | 决策项 | 结论 | 理由 |
| --- | --- | --- | --- |
| D1 | 产品定位与形态 | 纯单人自用；纯静态 Web/PWA + Git 仓库驱动 | 消灭服务器、数据库、推送通道与外接 LLM 成本 |
| D2 | 废弃原功能 3 与 DeepSeek | 砍掉 24h 巡检、免梯子正文搬运、安卓推送与 DeepSeek API | 改为按需喊 Antigravity 更新，零月费且语义提取质量更高 |
| D3 | 托管与仓库名 | GitHub Pages + Public 仓库 **`Guess00/oshi-calendar`** | 用户日常与更新均有梯子，0 元零折腾；仅存公开声优行程与推文时间链接 |
| D4 | 推特采集与展示范围 | Antigravity 内置浏览器（已登录态）；放弃 Replies，仅主页原创 + RT；第 1 阶段头像栏仅放 `@anzusaku1012`，`@pazyanai_chan` 仅作日程源 | 避免手动维护 Cookie/付费 API；RT 覆盖官宣情报且保持主页原生顺序 |
| D5 | 时间制与时区 | 全部统一 **东京时间 JST 0–24 小时制**（`00:00–23:59`） | 与自然日历一致，避免深夜 25:30 跨日歧义 |
| D6 | 推特记录 UI（INS 风格） | 独立「推特记录」Tab，顶部横向头像+ID 栏；点击后下方严格按 X 主页从新到旧排序（原创精确到分、无精确分则给大致时间；RT 保持主页相对顺序），零图文，新标签页跳原链 | 兼顾美观、直观筛选与顺序准确性 |
| D7 | 日程展示与数据分层 | ±7 天日期选择 + 竖向按时间排序列表；结构化源（番剧/Eventernote/YouTube/固定规则）+ 推文提取无损合并 | 固定与排期数据可预生成未来多周，多日未更新仍可按日滚动 |
| D8 | 更新流与 W1/W2 切换 | `AGENTS.md` + `data/config.json`（`pushMode`: `"W1"` / `"W2"`）；无网页后台编辑页，增删改均由 Antigravity 改仓库 JSON | 跨对话持久化工作流规范，一句话无缝切换审批/自动推送模式 |
