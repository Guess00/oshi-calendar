# Oshi Calendar

个人定制的日本女声优行程与推特更新记录纯静态站点（GitHub Pages 托管，全站统一日本标准时间 JST 0–24 小时制）。

- **在线访问**：`https://guess00.github.io/oshi-calendar/`
- **当前已接入声优**：橘杏咲（`@anzusaku1012`）

## 主要功能

1. **实时东京时钟**：顶部实时展示 JST `HH:mm:ss`（0–24 小时制）与日本曜日（月/火/水/木/金/土/日）。
2. **±7 天日程表**：支持选择当日东京时间前后一周的具体日期（单日视图 / 前后一周全览），按从早到晚展示番剧更新、线下活动、常规节目、嘉宾出演与固定周期专栏。
3. **INS 风格推特记录**：顶部头像栏快速切换关注声优，严格保留 X 主页顺序（原创 + RT，放弃 Replies），零图文零正文，点击新标签页直达原推链接。
